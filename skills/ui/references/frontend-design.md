# Frontend Design Summary

Design guidelines for elevating UI distinctiveness and aesthetic quality.
Apply only when explicitly requested.

## Design Thinking (Decide First)
- Purpose: What problem does this UI solve, and for whom?
- Tone: Choose one bold direction (e.g. minimal / brutalist / editorial / playful)
- Constraints: Technical constraints and a11y
- Differentiation: Decide the one memorable element of this UI

## Implementation Quality Standards
- Production-grade and actually functional
- Visually striking with a consistent direction
- Attention to detail (spacing, hierarchy, states)

## Design Guidelines
- Typography: An eye-catching display paired with a readable body
- Color: A clear primary color and a sharp accent
- Motion: Focus on one significant animation (avoid scattering)
- Space: Deliberately choose generous whitespace or high density
- Background: Atmospheric layering or texture (if appropriate)

## Notes
- What matters is the strength of intent, not how flashy the result is.
- Match implementation complexity to the design direction.
