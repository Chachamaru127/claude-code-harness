# Slide Quality Check - Slide Image Quality Assessment

Claude visually inspects slide images generated by Nano Banana Pro to ensure quality.

---

## Overview

This is the quality assessment logic executed in Step 4 of `/generate-slide`.
It evaluates both candidates for each pattern (Minimalist, Infographic, Hero Visual) and selects the best one.

---

## Assessment Flow

```
Receive 2 images per pattern
    |
    +--[Step 1] Assess each image individually
    |   +-- Score on 5 slide-specific criteria
    |   +-- Rate each criterion 1-5
    |   +-- Calculate overall score (weighted average)
    |
    +--[Step 2] Within-pattern comparison
    |   +-- Both score 3+: adopt the higher one
    |   +-- Only one scores 3+: adopt that one
    |   +-- Both score 2 or below: regenerate
    |
    +--[Step 3] Regeneration decision
        +-- Both NG: improve prompt and regenerate (max 3 times)
        +-- Retry limit reached: report to user
```

---

## Slide-Specific Assessment Criteria

### 5 criteria and weights

| Criterion | Weight | Description | Evaluation points |
|-----------|--------|-------------|-------------------|
| **Information delivery** | High (×3) | Does the slide convey the project's key points in one image? | Immediately understandable what the project is; value proposition is clear |
| **Layout balance** | High (×3) | Visual completeness, whitespace usage | Elements are well-organized; visual flow is natural |
| **Text readability** | Medium (×2) | Is AI-generated text legible? | No garbled text; font size is appropriate; contrast is sufficient |
| **Professionalism** | Medium (×2) | Does the quality hold up for business use? | Not cheap-looking; color usage is refined; visually consistent |
| **Brand consistency** | Low (×1) | Does it match the specified colors/tone? | Aligns with the specified tone; color does not deviate significantly |

### Overall score calculation

```
Overall score = (Information delivery × 3 + Layout × 3 + Text readability × 2 + Professionalism × 2 + Brand consistency × 1) / 11
```

### Score definitions

| Score | Verdict | Description |
|-------|---------|-------------|
| 5 | Excellent | Perfect, adopt immediately |
| 4 | Good | Good, can be adopted |
| 3 | Acceptable | Within tolerance, adopt if nothing better |
| 2 | Poor | Problematic, regeneration recommended |
| 1 | Unacceptable | Cannot be used, must regenerate |

### Adoption threshold

```
Adoption threshold = 3 (Acceptable or above)
```

## Pattern-Specific Additional Checks

### Minimalist

| Check item | Pass criteria |
|------------|---------------|
| Whitespace usage | Sufficient whitespace, not cramped |
| Typography | Font is readable, hierarchy is clear |
| Simplicity | Elements are kept to a minimum |

### Infographic

| Check item | Pass criteria |
|------------|---------------|
| Information structure | Visually divided into sections |
| Icon/diagram usage | Visual elements are present, not just text |
| Data visualization | Numbers and features are diagrammed |

### Hero Visual

| Check item | Pass criteria |
|------------|---------------|
| Visual impact | Bold visual that catches the eye |
| Tagline | Message is clear and readable |
| Emotional appeal | Conveys the project's value intuitively |

## Claude Assessment Prompt

### Image evaluation prompt

````text
Please evaluate the following slide image.

## Subject
- Pattern: {pattern_name} (Minimalist / Infographic / Hero Visual)
- Project: {project_name}
- Summary: {project_description}
- Expected tone: {tone}

## Assessment Criteria (each 1-5)
1. Information delivery (weight: high) — Does a single slide convey the project's key points?
2. Layout balance (weight: high) — Visual completeness, whitespace usage
3. Text readability (weight: medium) — Is the text legible? Any garbled characters?
4. Professionalism (weight: medium) — Does the quality hold up for business use?
5. Brand consistency (weight: low) — Does it match the specified colors/tone?

  "improvement_suggestions": ["suggestion 1", "suggestion 2"]

```
````

## Within-Pattern Selection Logic

### Basic rules

```
1. Both score 3+:
   → Adopt the higher-scoring one
   → Same score → use priority criteria:
      1. Higher information delivery
      2. Higher professionalism
      3. Default to candidate 1

2. Only one scores 3+:
   → Adopt the one scoring 3+

3. Both score 2 or below:
   → Regenerate (improve prompt)
   → If retry limit (3) is reached:
      → Provisionally adopt the higher-scoring one and report to user
      → User chooses to continue or skip
```

### Retry control

```
max_retries = 3 (per pattern)
```

| Retry | Strategy |
|-------|---------|
| 1st | Generate with initial prompt |
| 2nd | Reflect quality feedback; add specific modifiers |
| 3rd | Major style change; add more specific composition instructions |
