# Image Quality Check - Claude Image Quality Assessment

Claude visually inspects images generated by Nano Banana Pro and ensures quality.

---

## Overview

This is the quality assessment logic that runs in Step 4 of `image-generator.md`.
Claude analyzes the 2 generated images and determines whether to accept or reject them.

## Assessment Flow

```
Receive 2 images
    │
    ├── [Step 1] Evaluate each image individually
    │   ├─ Basic quality check
    │   ├─ Scene fit check
    │   └─ Brand consistency check
    │
    ├── [Step 2] Aggregate assessment results
    │   ├── Both OK → Proceed to Step 3
    │   ├── 1 OK → Adopt the OK one
    │   └── Both NG → Regenerate
    │
    └── [Step 3] Select the best of the 2 images
        ├─ Comparative evaluation
        └─ Decide on the selected image
```

---

## Assessment Criteria

### 1. Basic Quality Check

| Check Item | Pass Criteria | NG Example |
|-------------|---------|------|
| **Sharpness** | No blur or noise | Out of focus, excessive noise |
| **Composition** | Well-balanced | Off-center, clipped, unnatural placement |
| **Color** | Natural and consistent | Color banding, unnatural saturation |
| **Artifacts** | No generation noise | Distortions, repetitive patterns |
| **Resolution** | Meets specified resolution | Low resolution, upscale degradation |

### 2. Scene Fit Check

| Check Item | Pass Criteria | NG Example |
|-------------|---------|------|
| **Subject match** | Expresses the prompt's subject | Unrelated content |
| **Style match** | Consistent with the specified style | Style mismatch |
| **Purpose fit** | Appropriate for the scene's purpose | Composition unsuitable for video |
| **Text quality** | Readable if text is present | Garbled text, unnatural text |

### 3. Brand Consistency Check

| Check Item | Pass Criteria | NG Example |
|-------------|---------|------|
| **Color scheme** | Harmonizes with brand colors | Color mismatch |
| **Tone** | Professional | Too casual, cheap |
| **Consistency** | Unified with other scenes | Looks out of place |

---

## Evaluation Scoring

### Score Definition

| Score | Assessment | Description |
|--------|------|------|
| 5 | Excellent | Perfect, adopt immediately |
| 4 | Good | Good quality, can be adopted |
| 3 | Acceptable | Within acceptable range, adopt if no alternative |
| 2 | Poor | Has issues, regeneration recommended |
| 1 | Unacceptable | Unusable, regeneration required |

### Adoption Threshold

```
Adoption threshold = 3 (Acceptable or above)
```

### Selection Logic When Comparing 2 Images

```
When both are above the threshold:
  → Adopt the one with the higher score
  → If tied, decide by the following:
     1. The one with higher scene fit
     2. The one with higher brand consistency
     3. Adopt the first image (default)
```

## Claude Assessment Prompts

### Image Evaluation Prompt

````text
Please evaluate the following image.

## Evaluation Target
- Scene: {scene_name}
- Purpose: {scene_purpose}
- Expected style: {expected_style}
- Brand colors: {brand_colors}

## Evaluation Criteria
1. Basic quality (sharpness, composition, color, artifacts)
2. Scene fit (subject, style, purpose)
3. Brand consistency (color scheme, tone, coherence)

## Output Format
```json
{
  "score": 1-5,
  "verdict": "OK" | "NG",
  "strengths": ["strength 1", "strength 2"],
  "issues": ["issue 1", "issue 2"],
  "improvement_suggestions": ["suggestion 1", "suggestion 2"]
}
```
````

{image_b_evaluation}

## Regeneration Instructions on NG

### Improved Prompt Generation

```
The previous image was rejected.

## Issues
{issues}

## Improvement Suggestions
{improvement_suggestions}

## Revised Prompt
Please generate a prompt that addresses the following points:
1. {improvement_1}
2. {improvement_2}
```

### Adjustment Strategy During Regeneration

| Issue Category | Adjustment Strategy |
|-------------|---------|
| Composition issues | Add `centered composition`, `balanced layout` |
| Color issues | Add specific color specifications (HEX) |
| Style mismatch | Make style specification more specific |
| Text quality | Add `no text`, overlay text afterwards |
| Quality degradation | Add `high quality`, `4K`, `detailed` |

## Bypassing Assessment

### Force Accept

```
If the user specifies "this image is fine":
→ Skip quality check and adopt
```

### Threshold Adjustment

```
If the user specifies "be stricter":
→ Raise acceptance threshold to 4

If the user specifies "just use what you have":
→ Lower acceptance threshold to 2
```
