# /brainstorm - Socratic Design Session

段階的な質問を通じて、プロジェクトの目的・制約・設計を明確化します。

## Quick Reference

- "アイデアを整理したい" → `/brainstorm`
- "何を作るか相談" → `/brainstorm`
- "設計を詰めたい" → `/brainstorm`

---

## Socratic Method の原則

### 1. 1回1質問

```
❌ 複数の質問を同時に
   「誰が使いますか？どんな機能が必要ですか？予算は？」

✅ 1つずつ順番に
   「誰が使いますか？」
   → 回答を待つ
   「どんな機能が必要ですか？」
   → 回答を待つ
```

### 2. 選択肢優先

```
❌ 自由記述
   「どんなアプリを作りたいですか？」

✅ 選択肢を提示
   「どんなタイプのアプリですか？」
   a) Web アプリ
   b) モバイルアプリ
   c) CLI ツール
   d) API サーバー
```

### 3. 段階的検証

```
200-300語ごとに確認:
「ここまでの理解は合っていますか？」
```

### 4. 代替案の必須提示

```
決定前に必ず 2-3 の選択肢を比較:

| 案 | 概要 | メリット | デメリット |
|----|------|---------|-----------|
| A  | ...  | ...     | ...       |
| B  | ...  | ...     | ...       |
| C  | ...  | ...     | ...       |

推奨: 案B — 理由: ...
```

## 対話フロー

### Phase 1: Purpose（目的の深堀り）

```markdown
🎯 **最初の質問**

このプロジェクトで**一番解決したい問題**は何ですか？
```

↓ 回答を待つ

```markdown
🤔 **なぜそれが問題なのですか？**

（真の目的を探る）
```

↓ 回答を待つ

```markdown
✅ **成功の定義**

「これができたらOK」と言える**具体的な1シーン**を教えてください。
```

### Phase 2: User（ユーザーの明確化）

```markdown
👤 **使う人について**

a) 自分だけ
b) チーム（5人以下）
c) チーム（5人以上）
d) 一般公開
```

↓ 回答を待つ

```markdown
📱 **使う環境は？**

a) デスクトップ（ブラウザ）
b) デスクトップ（アプリ）
c) モバイル
d) CLI / ターミナル
e) 複数
```

### Phase 3: Constraints（制約の確認）

```markdown
⏰ **使える時間は？**

a) 1日
b) 1週間
c) 1ヶ月
d) 制限なし
```

↓ 回答を待つ

```markdown
🔧 **技術的な制約は？**

a) 使用言語/FW の指定あり → 何ですか？
b) 既存システムとの連携必須 → どのシステム？
c) 特定のホスティング先 → どこ？
d) 特にない
```

### Phase 4: Alternatives（代替案比較）

```markdown
📊 **3つのアプローチを提案します**

| 案 | 概要 | 工数 | 拡張性 | 推奨 |
|----|------|------|--------|------|
| A | シンプル実装 | 小 | 低 | |
| B | 標準的実装 | 中 | 中 | ⭐ |
| C | 本格実装 | 大 | 高 | |

**推奨: 案B**
理由: YAGNI の原則に従い、必要十分な機能で開始。
      将来拡張が必要になったら案C へ移行可能。

どれにしますか？（または別の案があれば教えてください）
```

### Phase 5: Validation（最終確認）

```markdown
📝 **設計の概要**

## プロジェクト: {名前}

### 目的
{1-2文で}

### ユーザー
{誰が、どこで}

### 主要機能
1. {機能1}
2. {機能2}
3. {機能3}

### 技術選定
- 言語: {言語}
- フレームワーク: {FW}
- データ: {DB/ストレージ}

### スコープ
- MVP: {最初に作るもの}
- 将来: {後で追加するもの}

---

この内容で `/plan-with-agent` に進みますか？

1. OK、進む
2. 修正したい点がある
3. もう少し話したい
```

## 実行コマンド

### 基本

```bash
/brainstorm
```

### アイデアを添えて

```bash
/brainstorm タスク管理アプリを作りたい
```

## 出力

- **`/plan-with-agent` への入力情報**: 整理されたプロジェクト概要
- **意思決定の記録**: `.claude/memory/decisions.md` に追記（オプション）

## 設定

```yaml
# .claude-code-harness.config.yaml
planning:
  socratic_mode: true           # default: true
  max_questions_per_turn: 1     # default: 1
  require_alternatives: true    # default: true
```
