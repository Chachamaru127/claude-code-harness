# Alternatives Template

代替案比較テンプレート。決定前に必ず使用する。

---

## 基本テンプレート

```markdown
📊 **{N}つのアプローチを提案します**

| 案 | 概要 | {評価軸1} | {評価軸2} | 推奨 |
|----|------|----------|----------|------|
| A | {概要} | {評価} | {評価} | |
| B | {概要} | {評価} | {評価} | ⭐ |
| C | {概要} | {評価} | {評価} | |

**推奨: 案{X}**
理由: {なぜこれが最適か}

どれにしますか？
```

## 使用ルール

1. **決定前に必ず提示**: 技術選定、設計判断の前に必ず複数案を比較
2. **推奨を明示**: 必ず1つを推奨し、理由を説明
3. **評価軸を適切に**: ユーザーの関心に合わせた評価軸を選ぶ
4. **トレードオフを説明**: 各案のメリット・デメリットを明確に
5. **「別の案」を許容**: 「または別の案があれば教えてください」を添える
